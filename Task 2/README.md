# To-Do List Web App

A simple To-Do list web app made using HTML, CSS, and Vanilla JavaScript.

## Features
- Add new tasks
- Mark tasks as complete (click on task text)
- Delete tasks
- Press Enter to add task
- No page reload, instant UI update

## Tools Used
- VS Code
- Live Server
- Chrome Browser

## How to Run
1. Download or clone the repo
2. Open index.html in browser
3. Or use Live Server extension in VS Code
